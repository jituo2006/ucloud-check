## 当前运行方式

- 监测总时段：北京时间 **07:00–21:00**。
- 课前 10 分钟至下课，每分钟检查云邮课堂状态。
- 已发现进行中课堂时，继续每分钟检查，最晚到 21:00。
- 导入课表后，课外不再每半小时扫描课程与课堂；每半小时仅检查本人身份、维持登录和按需刷新令牌。
- 没有导入课表时才退回旧的半小时课堂扫描。
- 签到处理仍关闭；时间表已接通，不等于真实签到状态字段已经校准。

例如：2026-11-13“智能软件工程”上课 15:40–17:20，对应 15:30 起每分钟检查；2026-11-14 实践课上课 13:00–17:20，对应 12:50 起每分钟检查。

备注中没有明确星期和节次的在线课、形势与政策等不能生成可靠窗口，未推测上课时间。调课表今后发生变化时需要重新同步；本次是读取整学期快照，尚未实现无需浏览器登录的每日教务同步。

## 代码与复用

- `cloudflare/timetable.mjs`：周次范围、间断周、节次时间展开；重复格去重，不猜测不支持的规则。
- `cloudflare/schedule.mjs`：07:00–21:00 时间限制、课前窗口和每分钟频率判断。
- `cloudflare/worker.mjs`：D1 课表保存、课表驱动监测及课外会话维护。
- `cloudflare/import-timetable.mjs`：将本地课表规则转换后上传，输出导入条数，不输出密钥。

本地规则文件已存在时可重新导入：

```bash
pnpm cf:import-timetable
```

也可传入另一个同格式文件：`pnpm cf:import-timetable /absolute/path/timetable.json`。这不会重新从教务取数据，需要先通过登录后的“全部”课表视图刷新文件。
